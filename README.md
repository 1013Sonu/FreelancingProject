# FreelanceHub - Freelancing Platform (MERN Stack)

FreelanceHub is a full-featured freelancing platform that connects clients with skilled freelancers. It allows clients to post projects, hire professionals, and manage work, while freelancers can bid on jobs, manage their profiles, and receive payments. Built using the MERN stack, this platform focuses on speed, scalability, and usability.

## 🛠️ Tech Stack

### 💻 Frontend
- **React.js** - Core UI Framework
- **Redux Toolkit** - State Management
- **React Router** - Client-Side Routing
- **Tailwind CSS** - Styling
- **Axios** - HTTP Requests

### 🌐 Backend
- **Node.js** - Server Environment
- **Express.js** - Web Framework for APIs
- **MongoDB** - NoSQL Database
- **Mongoose** - MongoDB ODM

### 🔐 Authentication & Security
- **JWT (JSON Web Tokens)** - Authentication
- **bcrypt.js** - Password Hashing
- **Helmet & CORS** - Security Headers & Cross-Origin Requests

## 📦 Features

### 👤 User Features
- User Registration/Login (JWT-based auth)
- Create and edit profiles (Client & Freelancer)
- Upload profile picture and portfolio
- View dashboard with activity summary

### 🧳 Client Features
- Post projects with details (budget, category, duration)
- View freelancer profiles and portfolios
- Accept bids and assign freelancers
- Chat system to communicate with freelancers
- Leave reviews and ratings

### 💼 Freelancer Features
- Browse available projects
- Bid on projects with a custom proposal
- Manage ongoing projects
- Receive payments
- View and manage their reviews

### 📬 Common Features
- Real-time notifications (WebSocket planned or Firebase)
- Search and filter for projects and freelancers
- Responsive UI (mobile/tablet friendly)
- Admin panel for managing users and content
